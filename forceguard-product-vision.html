How It Works
4-Layer Testing Architecture
Tests run in sequential layers. Blocking layers must pass before the next executes. This catches issues at the cheapest, fastest level first.
Layer 1
Deploy Validate
~30-60 seconds
Blocking
  • Syntax validation
  • Dependency checks
  • Reference integrity
  • Metadata compilation
Layer 2
Apex Tests
~2-5 minutes
Blocking
  • Unit test execution
  • Code coverage (85%+)
  • Governor limit checks
  • Bulk data assertions
Layer 3
Data Scenarios
~5-15 minutes
Verification
  • End-to-end workflows
  • Flow execution paths
  • Cross-object logic
  • Real business scenarios
Layer 4
Static Analysis
~1-2 minutes
Quality Gate
  • Security patterns
  • Best practice checks
  • Code smells
  • Complexity scoring

Data Model
Purpose-built Salesforce objects
Clean, well-structured custom objects that track everything from test definitions to execution results.
Regression_Test_Suite__c
Test Suite
Groups tests per product. One suite per product, versioned and org-targeted.
  • Name (Text)
  • Product_Name__c (Text)
  • Version__c (Text)
  • Target_Org__c (Text)
  • Description__c (Long Text)
  • Is_Active__c (Checkbox)
  • Total_Test_Cases__c (Rollup)
  • Last_Run_Date__c (DateTime)
  • Last_Run_Status__c (Picklist)
Regression_Test_Case__c
Test Case
Individual test definitions with steps, assertions, perspective tags, and priority.
  • Name (Auto-Number)
  • Test_Suite__c (Lookup)
  • Title__c (Text)
  • Description__c (Long Text)
  • Test_Layer__c (Picklist 1-4)
  • Category__c (Picklist)
  • Perspective__c (Picklist)
  • Priority__c (Picklist P0-P2)
  • Steps__c (Long Text)
  • Expected_Result__c (Long Text)
  • Assertion_Type__c (Picklist)
  • Is_Active__c (Checkbox)
Regression_Test_Run__c
Test Run
Execution instances. Records when tests ran, who triggered them, and the overall outcome.
  • Name (Auto-Number)
  • Test_Suite__c (Lookup)
  • Run_Date__c (DateTime)
  • Triggered_By__c (Picklist)
  • Status__c (Picklist)
  • Total_Tests__c (Number)
  • Passed__c (Number)
  • Failed__c (Number)
  • Skipped__c (Number)
  • Duration_Seconds__c (Number)
  • Code_Coverage__c (Percent)
Regression_Test_Result__c
Test Result
Individual pass/fail per test case per run. The granular record of what happened.
  • Test_Run__c (Master-Detail)
  • Test_Case__c (Lookup)
  • Status__c (Picklist)
  • Actual_Result__c (Long Text)
  • Error_Message__c (Long Text)
  • Stack_Trace__c (Long Text)
  • Duration_Ms__c (Number)
  • Layer__c (Picklist)
  • Is_Regression__c (Checkbox)
Regression_Config__mdt
Configuration
Custom Metadata Type for thresholds, org aliases, feature toggles, and settings.
  • Coverage_Threshold__c (Percent)
  • Org_Alias__c (Text)
  • Auto_Ticket_Enabled__c (Checkbox)
  • Flaky_Threshold__c (Number)
  • Notification_Email__c (Email)
  • Schedule_Frequency__c (Picklist)
  • Enabled_Layers__c (Multi-Picklist)
Test_Coverage_Snapshot__c
Coverage Snapshot
Point-in-time coverage metrics. Tracks improvement over time for reporting.
  • Snapshot_Date__c (Date)
  • Apex_Coverage__c (Percent)
  • Flow_Coverage__c (Percent)
  • VR_Coverage__c (Percent)
  • Total_Metadata__c (Number)
  • Tested_Metadata__c (Number)
  • Overall_Score__c (Percent)
